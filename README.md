# Nawshin Alam — Portfolio Website v1.0

A responsive, single-page academic portfolio built with plain HTML, CSS and JavaScript. It is ready for GitHub Pages and does not require any build tools.

## 1) Upload to your existing GitHub repository

Upload **all files and folders inside this directory** to the root of your repository. The structure should remain:

```text
YOUR-REPOSITORY/
├── index.html
├── style.css
├── script.js
├── README.md
├── .nojekyll
└── assets/
    ├── documents/
    │   └── Nawshin_Alam_CV.pdf
    └── images/
        └── ...
```

## 2) Turn on GitHub Pages

1. Open your repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**.
5. Click **Save**.
6. After a minute or two, GitHub will show your live website URL.

If the repository is named `YOUR-USERNAME.github.io`, the URL will normally be:

`https://YOUR-USERNAME.github.io/`

## 3) Easy edits

Open `index.html` in GitHub and click the pencil icon to edit text.

### Add LinkedIn / GitHub / Google Scholar / ORCID
Search for this sentence near the Contact section:

`Add your LinkedIn, GitHub, Google Scholar and ORCID URLs...`

You can replace it with buttons/links after you have the URLs. If you send me the links, I can prepare the exact code for you.

### Change the CV
Replace:

`assets/documents/Nawshin_Alam_CV.pdf`

with your updated CV, keeping the same filename to avoid changing the website code.

### Change photos
Replace files inside `assets/images/` while keeping the existing filenames, or update the image paths in `index.html`.

## 4) Local preview

You can simply double-click `index.html` to preview it in a browser. For the most accurate preview, use VS Code with the **Live Server** extension.

## Notes

- No private residential address is published on the website.
- Public contact uses email and city/country only.
- The site uses no external framework or CDN, so it is lightweight and easy to maintain.
- The DOI link is active.
